# 经典三人规则基准

核对日期：2026-11-08。代码基线：`8b5c678`。目标按用户指定采用腾讯官方公开经典三人规则，不宣称对齐某个未指定客户端版本的全部内部判定。

## 来源与范围

主要来源：[QQ游戏官网《欢乐斗地主（手游）》“游戏规则”](https://qqgame.qq.com/app/gamedetail_10302.shtml)，其中“二、叫牌”“三、抢地主”“六、出牌”直接给出本次叫抢、流局、基本牌型和比较规则。排除其他厂商的同名游戏、竞技二打一叫分规则、癞子和四人模式。明牌、额外加倍不在本次范围。

飞机单翅允许拆对子还参考了[腾讯《欢乐斗地主》专区的具体牌例](https://game.xiaomi.com/viewpoint/1359077112_1652416223136_9)：`JJJQQQ` 带 `44`。这是游戏日报的玩法文章，属于辅助牌例，**不是腾讯官方细则或本次客户端实测**。

## 叫抢与流局

- 首叫座位随机，随后按现有座位顺序 `(seat + 1) % 3` 行动。
- 每次发牌独立记录“不叫”资格；叫牌时不叫（含超时、离线超时默认不叫）者，这次发牌不能再抢。重新发牌清空记录。
- 首个叫地主者为暂定地主，底倍 1。由其下家起，跳过不叫者，每个有资格的其他玩家各决策一次。
- 有人抢后，原叫者最后可反抢一次；无人抢则直接确定原叫者。抢或不抢都消耗该玩家唯一的抢地主机会。每次实际抢地主翻倍。
- 三人都不叫就洗牌、重新发 17/17/17 + 3 张，并重新随机首叫。连续流局次数只用于日志、采集，不再触发强制指定地主。官网唯一提到的全不叫指定地主例外依赖“明牌”，本项目没有该功能。

以 A 为首叫座位，顺序如下（玩家自身选择抢/不抢不改变其余玩家的顺序）：

| 叫牌 | 抢地主顺序 | 结束 |
| --- | --- | --- |
| A 叫 | B → C；任一人抢后 → A 反抢 | 最后叫/抢者为地主 |
| A 不叫，B 叫 | C；C 抢后 → B 反抢 | A 永不参与抢 |
| A、B 不叫，C 叫 | 无 | 直接确定 C |
| A、B、C 不叫 | 无 | 重新发牌、重新叫 |

## 牌型边界与证据限制

普通牌必须同牌型、同长度才能比较；只比较三张、飞机机身或四张的点数，不比较带牌。王炸不能压另一个王炸；四带二不具有炸弹的跨牌型压制能力。顺子至少五张、连对至少三对、飞机至少两组三张，顺牌主体不能含 2 或王。

| 牌例 | 本项目统一判定 | 依据/限制 |
| --- | --- | --- |
| `33344456`、`33344455` | 飞机带单 | 官网基本牌型，重复单翅有上述辅助牌例 |
| `333444555667`、`3334445556667788` | 飞机带单 | 同一单翅点数最多取两张，与拆对子一致 |
| `3334445566` | 飞机带对 | 两个不同点数的对子 |
| `333344`、`333345` | 四带二 | 保留已有“带两单，可同点”规则 |
| `33334455` | 四带两对 | 官网明确例型；不算炸弹 |
| `333444`、`333444555666` | 裸飞机 | 不重新解释成较短飞机带三张翅膀 |
| `33334445` | 无效 | 保留机身点数不能兼作翅膀的限制 |
| `33334444`、`3334445555` | 无效 | 保留不将四张拆成两对翅膀的限制 |

**未获官网逐项确认的细节**：机身第四张是否可作翅膀、三张或四张重复单翅、双四张是否按四带两对处理、带双王的额外限制、多解牌组是否按上家牌型重解释。公开规则页未提供这些特殊牌例，本次不臆造客户端结论，按最小改动保留 Go 服务端现有边界，并收紧 Python 的不一致动作。若后续提供目标版本的官方补充细则或实测证据，应同步调整三端及共用牌例。

## 回归约定

`testdata/classic-rules.json` 是 Go 判型/比较/自动出牌、Python 判型/合法动作、Web 判型/提示共用的牌例表；使用项目的点数编码（3–14、2=15、小王=16、大王=17），Python 测试转为 DouZero 编码。它明确记录项目当前口径，不把未确认边界冒充腾讯官方认证结果。
